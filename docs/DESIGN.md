## 1. 协议定位声明（学术风险规避）

> **⚠️ 本节为全文最重要的声明，任何引用本仿真结论的工作都必须同时引用本节。**

### 1.1 核心声明

**本仿真采用 DV（距离矢量）+ 路径矢量路由协议，其定位是"分布式路由脆弱性的参照系（reference frame）与攻击效果上界（upper bound）"，而非对 Starlink 真实路由实现的复刻或模仿。**

具体而言：

| 声明要点 | 内容 |
|---|---|
| **DV 的角色** | 作为一个**故意选择的最脆弱基线**——DV 无条件信任邻居通告（见 [`THREAT_MODEL.md`](./THREAT_MODEL.md) §6 TA-2/TA-3），是路由攻防研究中公认的"低垂果实"。选择它是为了**放大攻击可观测性**，使黑洞/干扰的效果在实验中清晰可测。 |
| **不声称模仿 Starlink** | 本仿真**不断言** Starlink 使用 DV 协议。任何将本仿真结果解读为"Starlink 真实路由如此脆弱"的说法都是**误用**。 |
| **攻击效果上界** | 由于 DV 缺乏现代协议（如链路状态 + 认证、源路由、确定性预计算）的防护，本仿真得到的攻击损害（如 E3 交付率 −17%）应理解为**脆弱性上界**，而非对任何真实系统的损害估计。 |

### 1.2 Starlink 真实路由的公开认知（与本仿真的差异）

公开文献与工程分析普遍表明，Starlink 这类拥有**全球星历可预测性**的 LEO 星座，其路由设计倾向于**确定性 / 预计算路由（deterministic / precomputed routing）**：

- **星历公开性**：卫星轨道由 TLE 描述且长期可预测，网络拓扑（ISL 连接关系）在很大程度上是**时间的确定函数**，可离线预计算。
- **集中式 / 预规划倾向**：真实系统可利用这一可预测性，在地面或星上离线规划路径（类似"时间扩展图 / snapshot sequence"路由），而非依赖在线分布式 DV 收敛。
- **快照式路由**：将连续时间切分为拓扑近似不变的快照（snapshot），每个快照使用预计算的最优路径——这与本仿真"控制面在线收敛"的范式**根本不同**。

> **重要说明**：上述关于 Starlink 真实路由的描述基于公开工程分析与学术推测，**SpaceX 未公开其路由协议的完整规范**。因此本节表述为"倾向于 / 公开认知表明"，而非确定性断言。相关推测性文献见 §4，其确切结论**待核验**。

### 1.3 本仿真的缺口与对外推的影响

| 缺口 | 描述 | 对结论外推的影响 |
|---|---|---|
| **未纳入预计算/集中式路由对照** | 本仿真**没有**实现确定性预计算路由或集中式控制面作为对照组 | 无法量化"DV 相对确定性路由的额外脆弱性"；所有攻击损害数字**只适用于 DV 范式** |
| **单一路由范式** | 仅 DV + 路径矢量，无链路状态（如 OSPF 类）、无源路由对照 | 不能声称结论覆盖"所有分布式路由" |
| **脆弱性上界而非期望值** | DV 的无认证假设放大了攻击效果 | 对真实（疑似确定性/带防护）系统，实际损害**大概率显著低于**本仿真数字 |

> **外推结论**：本仿真的合法学术用途是——（1）验证攻击机制在"无认证分布式路由"下的**可行性与放大效应**；（2）为 STMP 防御机制（ODTA/TESLA/几何下界/信誉+FRR）提供**攻击基线与评测靶场**。**非法用途**是——将 E2/E3 的交付率数字直接解读为 Starlink 或任何真实 LEO 系统的实际安全水平。

## 2. 仿真保留 vs 简化的 Starlink 特征（对比表）

| 维度 | 类别 | 仿真实现 | 与真实 Starlink 的关系 | 代码/数据锚点 |
|---|---|---|---|---|
| **TLE 数据源** | ✅ **保留** | 真实 CelesTrak 快照，10744 记录，SHA256 校验，2026-08-22 | 使用真实星历，非理想化模型 | `data/tle/starlink.tle` |
| **轨道传播** | ✅ **保留** | SGP4 传播内核（`sgp4` 库）+ `skyfield` 外部校验 | 采用标准 SGP4/SDP4 摄动模型，与真实轨道预测一致 | `starlink_sim/topology/isl.py` `propagate_satellite` |
| **ISL 建链规则** | ✅ **保留** | 面锚定 +Grid：同面前后各 1 + 异面相邻面各 1 + 面外几何回退 | 锚定 Wood / Bhattacherjee & Singla 的 +Grid 拓扑规则，边重合率 >99%（kNN 仅 41%） | `isl.py` `build_edges_for_epoch` |
| **壳层结构** | ✅ **保留** | 53°（主壳层, P=72）、97.5°（极轨, P=90）、70°、43° 多壳层分类 | 反映 Starlink 真实多倾角壳层部署 | `starlink_sim/orbit/shells.py` |
| **动态 epoch 拓扑** | ✅ **保留** | 30 s epoch 间隔，逐 epoch 重新计算边集，支持拓扑演化 | 保留 LEO 拓扑时变性（虽然单快照内变化较小） | `simulator.py` `run_ticks` / `edge_sets[epoch_idx]` |
| **路由协议** | ⚠️ **简化** | DV + 路径矢量（在线分布式收敛） | 真实 Starlink 疑似**确定性/预计算路由**（§1.2）；本仿真刻意选最脆弱范式 | `routing_dv.py` |
| **数据面模型** | ⚠️ **简化** | 事后流评估（`compute_path` 查表转发），**无队列/无拥塞/无缓冲丢包** | 真实系统有排队、拥塞控制、QoS；本仿真只评交付率/跳数/传播时延 | `simulator.py` `DataPlane.evaluate_flows` |
| **控制面安全** | ⚠️ **简化** | **无认证/无签名/无加密**，通告明文广播（`dst=-1`） | 真实系统应有报文认证；本仿真刻意暴露此缺口作为攻击面 | `DVMessage`（无认证字段） |
| **时延模型** | ⚠️ **简化** | 仅传播时延 `dist / c`（`SPEED_OF_LIGHT=299792.458 km/s`），**无处理/排队时延** | 真实端到端时延含星上处理、地面段、排队；本仿真为几何下界 | `simulator.py` `compute_path` `total_delay += dist/SPEED_OF_LIGHT*1000` |
| **数据面时延实测** | ⚠️ **已知限制** | 位置缓存缺失时 `avg_latency_ms` 恒为 0（见 [`DECISIONS_AND_ISSUES.md`](./DECISIONS_AND_ISSUES.md) 观察 1） | 当前无法评估攻击对时延的影响 | `data/snapshots/positions_per_epoch.pkl`（缺失） |

> **保真度总评**：本仿真在**轨道/拓扑层（物理真实性）高度保真**（真实 TLE + SGP4 + +Grid 建链），在**网络层（协议/数据面）刻意简化**以放大攻击可观测性。这种"物理真实 + 网络简化"的组合是有意的学术设计：物理层保证拓扑可信，网络层的简化则明确了 §1 的脆弱性上界定位。

## 3. 数据保真度硬约束

本节为**强制性约束**，任何后续实验/分支都必须遵守，以保证结果可复现且具备学术可信度。

| 约束 ID | 硬约束 | 具体要求 | 违反后果 |
|---|---|---|---|
| **DC-1** | **全程使用真实 TLE** | 数据源锁定 CelesTrak 2026-08-22 快照，10744 条记录 | 使用合成/理想星历将丧失物理真实性，结论不可外推到真实星座 |
| **DC-2** | **SHA256 完整性校验** | TLE 文件 SHA256 = `852E79A4D2EB28EE5864FC86BC204CB50DDE2FEE83F27A7F5B9D2356932FC97B` | 校验失败说明数据被篡改/漂移，结果不可信 |
| **DC-3** | **禁用 Walker / 理想星座模型** | **不得**用 Walker-delta 等参数化理想星座替代真实 TLE | 理想星座抹平了真实轨道摄动与壳层不规则性，边重合率与拓扑演化失真 |
| **DC-4** | **锁定单一快照保证可复现** | 全部实验使用同一 TLE 快照（2026-08-22），**不得**混用不同日期 TLE | 避免每日 TLE 漂移导致跨实验不可比 |
| **DC-5** | **固定随机种子** | 实验 seed ∈ {42, 43, 44}，攻击者选择/流量生成/丢包均由 seed 决定 | seed 未固定则结果不可复现 |

**数据源指纹**：

```
来源:      CelesTrak (https://celestrak.org/)
抓取日期:  2026-08-22
记录数:    10744
文件:      data/tle/starlink.tle
SHA256:    852E79A4D2EB28EE5864FC86BC204CB50DDE2FEE83F27A7F5B9D2356932FC97B
壳层分布:  53°(主壳层,P=72) / 97.5°(极轨,P=90) / 70° / 43°
仿真规模:  4284 节点 × 121 epochs (30s 间隔)
```

> **说明**：SHA256 前缀 `852E79A4` 与完整值来自 [`README.md`](../README.md) §🔑 数据源，本处引用同一指纹；如需重新校验，对 `data/tle/starlink.tle` 计算 SHA256 应得上述完整值。

## 5. 结论外推的边界与限制

汇总本仿真结论的**合法外推范围**，作为学术引用的护栏。

| 论断 | 是否可外推 | 边界说明 |
|---|---|---|
| "黑洞/干扰攻击在无认证 DV 路由下可显著降低交付率" | ✅ **可外推** | 适用于所有"无条件信任邻居通告"的分布式路由；这是协议族的通用脆弱性 |
| "本仿真验证了 STMP 防御机制的有效性靶场" | ✅ **可外推** | 作为攻击基线与评测环境的合法性 |
| "E3 交付率下降 17% 代表 Starlink 的实际安全水平" | ❌ **不可外推** | 违反 §1 协议定位声明；DV 是脆弱性上界，非 Starlink 真实实现 |
| "本仿真的时延数字反映真实端到端时延" | ❌ **不可外推** | 时延仅 `dist/c`，无处理/排队时延（§2）；且位置缓存缺失时恒为 0（DC 已知限制） |
| "本仿真覆盖了集中式/预计算路由的安全性" | ❌ **不可外推** | 未实现该对照组（§1.3 缺口） |
| "本仿真的拓扑/轨道建模反映真实 Starlink 星座" | ✅ **可外推（物理层）** | 真实 TLE + SGP4 + +Grid（§2 保留项、§3 硬约束）保证物理层保真 |

> **一句话总结**：**物理层可信，网络层为脆弱性上界。** 引用本仿真任何网络层结论时，必须同时声明其"分布式 DV 参照系"定位（§1），不得剥离该上下文单独引用损害数字。
